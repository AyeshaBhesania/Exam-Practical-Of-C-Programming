# C Language Practical Exam – README

## Aim

To implement basic C programs using loops, functions, pointers, and pattern printing concepts.

## Programs Included

1. **Factorial of a Number**

   * Accepts an integer from the user.
   * Uses a loop to calculate and display its factorial.

2. **Vowel Counter**

   * Reads a sentence from the user.
   * Uses a function to count occurrences of vowels (A, E, I, O, U).

3. **Leap Year Checker**

   * Uses a function to determine whether a given year is a leap year.

4. **Swapping Two Numbers Using Pointers**

   * Uses pointers and a function to swap two integer values.

5. **Pattern Printing**

   * Uses nested for loops to print a right-aligned star pattern.

## Concepts Used

* Variables and Data Types
* Loops (for loop)
* Functions
* Pointers
* Conditional Statements
* String Handling
* Pattern Printing

## Conclusion

These programs demonstrate the use of fundamental C programming concepts such as loops, functions, pointers, and decision-making statements.
